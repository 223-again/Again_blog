闭包让函数记住它出生时的环境。但这份“记忆”用不好，就会带来意料之外的行为。

## 经典的循环陷阱

下面这段代码，很多人第一次都会答错：

```
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 输出：3 3 3
```

原因是 `var` 没有块级作用域，三个回调共享同一个 `i`。把 `var` 换成 `let`，每次迭代都会创建新的绑定，输出就变成 0 1 2。

> 理解作用域，是理解闭包的前提。
